# Fund OS agent skills

Add organisation-specific Cursor skills here as subfolders, each containing a `SKILL.md`:

```
skills/
  local-env-build/SKILL.md
  fund-os-deploy/SKILL.md
  fund-os-tenancy/SKILL.md
```

Skills in this repo are **Fund OS–specific**. Global Cursor skills (create-rule, create-skill, etc.) remain under your user profile (`~/.cursor/skills-cursor/`).

When adding a skill:

1. Keep it focused on one workflow.
2. Link to `FUND-OS.md` and relevant service docs.
3. Mention any CI/CD or deployment constraints from `fund-os-ci-cd` and `fund-os-deployments`.
